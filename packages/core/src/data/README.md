# Bundled map styles

`runcast-light-map.json` is Runcast's Coastal Mist light basemap. It was
derived from the Positron style served by OpenFreeMap on 2026-07-19, retaining
the original OpenFreeMap tile, sprite, and glyph endpoints while changing the
cartographic paint palette.

The underlying OpenMapTiles schema and cartographic design are licensed under
CC BY 4.0 and require visible OpenMapTiles attribution. Map data comes from
OpenStreetMap. Product surfaces using this style must keep the corresponding
OpenFreeMap, OpenMapTiles, and OpenStreetMap credits visible.

- Source style: <https://tiles.openfreemap.org/styles/positron>
- OpenFreeMap: <https://openfreemap.org/>
- OpenMapTiles license: <https://github.com/openmaptiles/openmaptiles/blob/master/LICENSE.md>
